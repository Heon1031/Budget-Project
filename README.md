# 둘이자산

부부가 한 달에 얼마를 저축하고, 투자하고, 쓸지 미리 약속하고 공동 생활비를 함께 기록하는 가계부입니다. 휴대폰 홈 화면에 앱처럼 설치해 씁니다.

2026년 공식 사회보험 요율과 세금 구조를 반영해 두 사람의 실수령액을 추정하고, 목표자산·생활비·용돈·교육비·투자 가능액을 계산하는 신혼부부 자산형성 플래너입니다.

## 주요 기능

- **이번 달 약속:** 저축 · 투자 · 고정 지출 · 공동 생활비 · 각자 용돈 · 상의 기준 금액을 정하고 둘 다 합의
- **이거 사도 돼?:** 금액을 넣으면 남은 공동 생활비와 상의 기준으로 바로 답하고 기록
- **두 폰 연결:** 연결 코드 + 비밀번호. 기록은 폰에서 암호화해 Cloudflare에 보관
- **엑셀 내보내기:** 달마다 약속과 기록을 CSV로 내려받기

- 두 사람의 세전 연봉과 비과세 급여를 바탕으로 실수령액 자동 추정
- 국민연금·건강보험·장기요양·고용보험·소득세·지방소득세 공제 내역
- 실제 급여명세서 실수령액으로 덮어쓰기
- 각자의 실수령액을 100%로 두고 식생활, 문화·레저, 여행, 현금·용돈을 금액과 비율 양쪽에서 조절
- 예금·적금, 주식·펀드, 연금·IRP, 비상금의 실제 금액에서 투자 비율 자동 계산
- 전세·주택대출, 월세, 기타 대출, 청약과 공과금을 공통 주거비로 관리
- 현재 자산과 월 적립액만으로 1·3·5·10년 뒤 자산 계산
- 혼인신고 전후 세금 관련 참고 안내
- 입력값을 서버가 아닌 현재 브라우저에만 자동 저장

연봉만 입력한 경우 월 소득은 단순 추정치로 계산됩니다. 정확한 계획을 위해 급여명세서의 월 실수령액을 입력하세요. 앱의 권장 비율은 시작을 돕는 휴리스틱이며 공식 금융·세무 기준이 아닙니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```powershell
npm.cmd install
npm.cmd run db:local
npm.cmd run dev
```

## 배포 (Cloudflare Workers + D1)

1. `npx wrangler login`
2. `npx wrangler d1 create duri-budget` → 나온 `database_id`를 `wrangler.jsonc`에 넣기
3. `npm.cmd run db:remote` 후 `npm.cmd run deploy`
4. 자동 배포: GitHub 저장소 Secrets에 `CLOUDFLARE_API_TOKEN` · `CLOUDFLARE_ACCOUNT_ID`를 넣으면 main에 올릴 때마다 `.github/workflows/deploy.yml`이 배포합니다.

검증:

```powershell
npm.cmd test
```

## 데이터와 보안

- 연결 전: 계획은 이 폰의 `localStorage`에만 저장됩니다.
- 연결 후: 계획 · 약속 · 지출은 폰에서 AES-GCM으로 암호화한 뒤 서버(D1)에 보냅니다. 열쇠는 비밀번호에서 PBKDF2(60만 회)로 만들고, 꺼낼 수 없는 형태로 폰의 IndexedDB에만 둡니다. 서버는 비밀번호에서 따로 만든 확인값의 해시만 갖고 있어 내용을 볼 수 없습니다.
- 비밀번호를 10번 틀리면 그 가구는 15분 잠깁니다.
- 비밀번호를 잊으면 기록을 되살릴 수 없습니다. 폰의 화면 잠금이 마지막 방어선입니다.
