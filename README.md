# 둘이살림

두 사람의 소득에 맞춰 공동생활비와 저축 목표를 정하고, 선택한 비율로 각자 부담액을 계산하는 부부 가계부 초안입니다.

## 주요 기능

- 두 사람의 세전 연봉과 월 실수령액 입력
- 소득 비례, 반반, 직접 설정 분담 방식
- 주거비·식비·통신비 등 카테고리별 권장 예산
- 각자의 공동계좌 이체액과 남는 금액 계산
- 현재 지출 입력 시 초과 항목과 절약 가능액 제안
- 입력값을 서버가 아닌 현재 브라우저에만 자동 저장

연봉만 입력한 경우 월 소득은 단순 추정치로 계산됩니다. 정확한 계획을 위해 급여명세서의 월 실수령액을 입력하세요. 앱의 권장 비율은 시작을 돕는 휴리스틱이며 공식 금융·세무 기준이 아닙니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

검증:

```powershell
npm.cmd test
```

## 데이터

입력한 소득과 지출은 `localStorage`에 저장되며 서버나 외부 서비스로 전송되지 않습니다. 공용 기기에서는 우측 상단의 `입력 초기화`를 사용하세요.
