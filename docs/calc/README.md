코드: `app/lib/calc/` (`plan.ts` 실수령 · 바구니 · 흐름, `housing.ts` 집 마련), 해볼까 판정 `judgeWish`(`app/screens/wish-board.tsx`).
규제 숫자 출처 · 기준일: [housing.md](housing.md). 두 사람의 실제 돈 숫자는 이 저장소(공개)에 쓰지 않는다(`../가계부_개인기록/`).

## 계산: 바구니 (2026-11-04 바꿈)
두 사람이 실제로 쓰는 방식(아내 손글씨 메모)대로 **각자 실수령을 바구니별 %로 나누고, 바구니 안에 매달 나가는 항목을 담는다.**
- 기본 바구니: 저축·투자 50(모으기) · 생활비 25 · 자기관리 15 · 용돈 7(마음 편히) · 여행 3 · 예비 0. (2026-11-04: 1년 안 내 집 마련이라 「저축 50% 이상」 조언에 맞춤. 두 사람이 각자 바꿀 수 있다) 바구니는 더하고 지우고 이름 · 아이콘 · 종류를 바꿀 수 있다.
- 바구니 금액 = 실수령 × %. 항목 합이 넘으면 「넘침」.
- **마음 편히 쓸 돈** = 용돈 바구니에서 항목을 뺀 돈 + 어느 바구니에도 나누지 않은 돈.
- **1년 모일 돈** = 모으기 바구니의 항목 합(항목이 없으면 바구니 금액) × 12. 수익률은 넣지 않는다.
- 공동 통장 · 전세대출처럼 실제로 누가 내는 돈은 그 사람 바구니의 항목으로 넣는다(공동 몫을 비율로 나누는 계산은 쓰지 않음).
- 해볼까: 한 번 드는 돈은 마음 편히 쓸 돈과 비교. 매달 드는 돈은 자기관리 바구니에 남은 돈 → 마음 편히 쓸 돈 순서로 본다. 시작하면 자기관리 바구니에 항목으로 담긴다(둘이 하는 건 반씩).
