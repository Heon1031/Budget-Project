# 집 마련 계산 기준 (2026-11-03 조사)

앱의 집 마련 계산은 **추정**이다. 아래 숫자는 `app/lib/housing.ts`의 `RULES`에 있고, 화면에서 사용자가 바꿀 수 있다. 실제 대출 한도는 은행 심사로 정해진다.

| 항목 | 기본값 | 근거 · 상태 |
|---|---|---|
| 생애최초 LTV(수도권 · 규제지역) | 70% | 블로그 정리 여러 곳. 6개월 안 전입 의무. **공식 확인 필요** |
| 일반 LTV(규제지역 / 비규제) | 40% / 70% | 블로그 정리. **공식 확인 필요** |
| 구입 주담대 상한 | 집값 15억 이하 6억, 15~25억 4억, 25억 초과 2억 | 블로그 정리. **공식 확인 필요** |
| DSR(1금융권) | 40% | 블로그 정리 |
| 대출 금리 기본값 | 4.9% | 한국은행 2026년 9월 주담대 평균 4.88% |
| 스트레스 가산금리(수도권) | 1.5%p (출처에 따라 3.0%p) | 출처끼리 다름. 앱은 입력값으로 둔다. **확인 필요** |
| 생애최초 취득세 감면 | 최대 200만 원(12억 이하, 부부 모두 무주택) | 지방세특례제한법 제36조의3 설명 글. 300만 원 확대안 보도 있음 — 시행 확인 필요 |

## 자동으로 받는 것 (매일 오전 9시, `app/lib/market.ts`)
- **은행 주택담보대출 평균 금리:** 한국은행 ECOS 통계표 121Y006(예금은행 가중평균금리, 신규취급액) · 항목 BECBLA0302. 2026년 9월 4.88%. 집 마련 탭에서 「내 계산에 쓰기」로 반영한다. 운영 서버에는 `wrangler secret put ECOS_API_KEY`로 발급 키를 넣는다(로컬은 `.dev.vars`의 `sample` 키, 10줄 제한).
- **대출 규제 소식:** 금융위원회 보도자료를 제목 검색(주택담보 · DSR · LTV · 가계부채)해 최근 1년 글을 모은다. 앱은 새 글이 있으면 「확인 필요」를 띄울 뿐, **규제 숫자(LTV · 상한 · DSR)는 자동으로 바꾸지 않는다.** 사람이 보도자료를 읽고 `RULES`와 이 표를 고친다.
- 보도자료 페이지 구조가 바뀌면 `parseFscList`를 고쳐야 한다.
