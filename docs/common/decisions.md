# 결정 기록

- [2026-11-03] 서버는 Cloudflare 하나(Workers + D1). GitHub는 코드 보관 · 자동 배포만. AWS · Vercel · 구글 Apps Script는 쓰지 않는다.
- [2026-11-03] 기록은 폰에서 AES-GCM으로 암호화해 보낸다(종단 간 암호화). 비밀번호를 잊으면 복구 불가 — 대신 엑셀 내보내기 제공.
- [2026-11-03] 두 폰 연결은 연결 코드(22자) + 비밀번호. 10번 틀리면 15분 잠금.
- [2026-11-03] 관리법은 통장 쪼개기. 약속 항목 = 통장. 공동 생활비만 기록하고, 각자 용돈은 묻지 않는다.
- [2026-11-03] 주택 상황: 전세 · 월세에서 1년 안 내 집 마련. 집 목돈은 원금 보장 상품에만.
- [2026-11-03] 규제 숫자는 추정 · 입력값으로 두고 출처 · 기준일을 `docs/calc/housing.md`에 적는다.
- [2026-11-03] 주 색을 초록에서 푸른색(토스 느낌)으로 바꿈. 글꼴 Pretendard, 어두운 모드 지원.
- [2026-11-03] 금리는 한국은행 ECOS에서 매일 자동으로 받고, 대출 규제는 금융위원회 보도자료 소식만 알린다(숫자 반영은 사람이 확인 후).
- [2026-11-03] 자산 모아보기는 뱅크샐러드에 맡긴다. 이 앱 첫 화면은 「오늘 둘이 쓸 수 있는 돈」과 「내 집까지 남은 거리」.
- [2026-11-03] 앱의 자리를 「큰 흐름」으로 다시 정함: 고정지출(각자 · 공동) 목록 + 1년 모일 돈 + 이번 달 각자 마음 편히 쓸 돈 + 해볼까. 건별 지출 기록 · 약속 합의 · 월급날 체크 화면은 뺌(공동 생활비는 공동 고정지출 한 줄로).
- [2026-11-03] 자동으로 거래내역 읽기는 하지 않음 — 마이데이터 · 오픈뱅킹은 허가 사업자만 가능, 알림 읽기는 아이폰 불가 · 보안 원칙과 어긋남.
- [2026-11-03] 학원 · 취미는 개인 부담(본인 몫에서 먼저 뺌). 고정지출 분류를 학원·배움 / 운동·건강 / 취미로 나눔. 각자 월급 나누기 목표 비율(기본 40·10·50)을 정할 수 있게 함.
- [2026-11-03] 배포: Cloudflare 계정 하위 도메인을 nestwork로 정함(메일 주소가 드러나던 기본값 대신). 앱 주소 https://duri-budget.nestwork.workers.dev, D1 duri-budget(APAC). 버전별 미리보기 주소는 끔.
- [2026-11-03] 잠금은 앱 안에서: 연결 안 된 폰은 연결 화면만, 연결된 폰은 Face ID · 지문(패스키, WebAuthn) 또는 연결 비밀번호로 연다. 3분 넘게 나갔다 오면 다시 잠금. Cloudflare Access는 $0이어도 카드 등록이 필요해서 쓰지 않음.
- [2026-11-03] 연결을 비밀번호에서 QR로 바꿈: 처음 시작한 폰이 무작위 비밀값을 만들고 상대 폰이 QR(또는 복구 코드 붙여넣기)로 받는다. 받는 폰은 QR을 보여 준 사람의 반대쪽(남편/아내)이 된다. 주인 개념 없음. 잠금은 Face ID · 지문, 안 되면 폰 PIN(OS가 처리).
- [2026-11-04] 계산을 「바구니별 %」로 바꿈(두 사람 실제 방식). 고정지출 목록 · 필요/하고 싶은/모으기 목표 비율 · 공동 몫 나누기는 바구니로 대체. 개인 실제 숫자는 공개 저장소에 넣지 않고 `../가계부_개인기록/`에 둔다.
- [2026-11-04] 「방 나누기」는 채팅방(세션)을 여러 개 만드는 게 아니라 **문서 · 코드 폴더를 영역별로 나누는 것**이었음. 세션 3개를 멈추고 폴더를 나눔: 코드 `app/screens/` · `app/secure/` · `app/lib/{calc,server,secure}/`, 문서 `docs/{common,frontend,backend,calc,audit}/`, 안내 `docs/README.md`. 한 방에서 영역 폴더를 열어 일한다.

## 2026-11-04 · 비율을 바꾼 뒤 「바꿀 일」 정리
- 사용자 요청: 비율을 바꾸면 전과 비교해 실제로 바꿀 것(적금 줄이기 · 앱에서 신청)을 정리해 보여 주기.
- 다섯 역할(반대 · 개선 · 부부 사용자 · 금융 실무 · 토스/애플 UX)로 검토한 뒤 정함.
  - 채택: 기준 계획과 비교, 번호 순서(줄일 때 항목 → 이체, 늘릴 때 이체 → 항목), 정기적금 · 청약 · 연금 주의 문구, 「항목 합이 바구니보다 많아요」 줄, 합계 막대 기준 점선, 되돌리기는 날짜 + 확인.
  - 뺌: 줄마다 체크칸(앱이 은행 안을 볼 수 없어 「바꿨다」가 거짓 상태가 되고 다툼 거리가 됨) → 「다 바꿨어요 · 새 기준으로」 한 번.
  - 나중: 상대에게 「누가 무엇을 바꿨는지」 메모 · 알림(바꾼 사람 기록이 필요해 서버 · 보안 영역), 월급날 알림.
