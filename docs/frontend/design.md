# 화면 · 디자인 규칙

코드: `app/screens/`(5개 탭 · 그래프 `charts.tsx` · 금액 입력 `fields.tsx`), `app/page.tsx`, `app/globals.css`, `public/`.

## 디자인 규칙 (2026-11-03 다시 잡음)
- 글꼴: Pretendard Variable 하나로 통일(`public/fonts/pretendard`, OFL, 화면에 나온 글자 조각만 받음). 숫자는 고정폭 숫자(tabular-nums)로 줄을 맞춘다. 명조(Georgia)는 쓰지 않는다.
- 글자 크기 단계: 12(캡션) · 13(보조) · 15(본문) · 16(입력) · 18(소제목) · 22(제목) · 32(큰 숫자).
- 색: `app/globals.css` `:root`의 토큰만 쓴다. 주 색은 푸른색 `--brand`(#2f6fed, 토스 느낌의 밝은 파랑), 배우자 쪽 `--partner`, 상태는 `--good` · `--warn` · `--bad`와 각 `-weak` 배경. 진한 판은 `--hero-*`.
- 어두운 모드: 폰 설정을 따라 같은 토큰 이름을 다시 정의한다. 새 색이 필요하면 밝은 · 어두운 두 값을 함께 만든다.
- 숫자: 원 단위 쉼표, 큰 금액(집값 등)은 「6억 2,000만원」. 음수는 「○원 부족」처럼 말로 쓴다.
- 누르는 곳 44px 이상, 주 버튼 52px. 카드 하나에 주 버튼(`button.primary`) 하나.
- 추정 숫자에는 「추정」 표시와 기준일을 붙인다.

## 글보다 그림 (2026-11-03)
- 아이콘은 lucide-react(1.57.0) 하나만 쓴다. 분류 아이콘은 `app/screens/charts.tsx`의 `CATEGORY_ICONS`.
- 그래프는 `app/screens/charts.tsx`의 부품만 쓴다: 도넛(월급 나누기), 쌓이는 막대(1년 모이는 돈), 진행 고리(내 집), 가로 막대(분류 · 쓸 돈 대비).
- 그래프 3분류 색 `--chart-needs` · `--chart-wants` · `--chart-savings`는 색약 검증(dataviz validate_palette)을 밝은 · 어두운 모드 각각 통과한 값이다. 바꾸면 다시 검증한다. 주황은 배경 대비가 낮아 항상 범례에 % 숫자를 같이 단다.
- 문장은 한 줄. 긴 설명은 「계산 보기」「추정 기준」처럼 접어 둔다.
- 짧은 금액은 `shortWon`(「128만」「1.9억」).
- Tailwind 기본 class 이름(ring, shadow, border 등)과 겹치는 class를 만들지 않는다.

## 2026-11-04 정한 것
- **버튼 모양 하나로:** 큰 버튼 높이 52 · 둥글기 14 · 좌우 16, 작은 버튼 44 · 12 · 16, 아이콘 버튼 44×44 · 12, 두 칸 고르기 바깥 14 · 안쪽 10. 값은 `globals.css`의 `--btn-*`.
- **금액 단위는 화면 위 「단위」 필터 하나(원 · 만원 · 억원)**로 모든 금액 칸이 함께 바뀐다. 칸마다 단위 버튼을 두지 않는다. 기본 만원, 이 폰에만 기억.
- **예시값은 칸 안의 작고 옅은 안내 글자(placeholder)**로만 보이고, 칸을 누르면 사라져 바로 우리 숫자를 친다.
- **첫 화면 그래프:** 12달 계단 막대 대신 「1년 모일 돈 = 남편 몫 + 아내 몫」 한 줄 막대와 두 사람 금액.
- **흐름 탭은 한눈 보기만:** 「+○만 더 모으면 ○%」 같은 조정 안내는 흐름에 두지 않고 나누기 탭에서만 보여 준다.
