## 먼저 고칠 5개

1. **흐린 회색 글자 대비 부족** — 어디: 모든 탭의 보조 글(「남음 7만」 「계약금 10%」 「참고용 추정이에요」 등, 4.1~4.4). 왜: 밝은 데서 폰으로 보면 안 읽힘(기준 4.5). 고칠 것: `--ink-3`(#6b7684)을 회색 배경 위에서도 4.5 넘게 한 단계 진하게. 영역: 화면. **높음**
2. **단위 버튼(만원 · 원 · 억원) 대비 3.97** — 어디: 모든 금액 칸. 고칠 것: 파란 글자를 조금 진하게 하거나 연한 배경을 더 연하게. 영역: 화면. **높음**
3. **누르는 곳이 작음(40px 이하)** — 어디: 남편 · 아내 / 한 번 · 매달 / 수도권 · 그 밖 같은 두 칸 고르기(40px), 항목 지우기 휴지통(40×40), 항목 칸 단위 버튼(36×32), 설정의 이름 칸 · 「지금 맞추기」(36px). 왜: 엄지로 잘못 누름. 고칠 것: 높이 44px로. 영역: 화면. **높음**
4. **탭바 글자 11px · 「추정」 표시 9.6px** — 기준(12px) 미만. 고칠 것: 탭바 12px, 「추정」 배지 12px. 영역: 화면. **중간**
5. **나누기 탭 항목마다 「만원」 버튼 반복** — 한 바구니에 4~5개씩 같은 파란 버튼이 줄 서서 눈이 시끄럽다(애플 · 토스 느낌과 거리). 고칠 것: 항목 줄은 숫자 + 단위 글자만 보이고, 누르면 단위를 바꾸게(또는 바구니 머리에 단위 하나). 영역: 화면. **중간**

## 그 밖에 본 것 (낮음)

- 흐름 탭은 첫 화면으로 좋다: 「1년 뒤 모이는 돈」 큰 숫자 + 12달 막대, 각자 도넛 가운데 「쓸 돈」. 다만 도넛 아래 범례 줄이 길어 한 화면에 두 사람 「쓸 돈」까지만 보이고 아래는 스크롤.
- 나누기: 비율 칸 「50%」와 아래 「지금 35.2% · 목표 50%」가 둘 다 %라 처음 보면 헷갈릴 수 있다 → 「목표 50% 중 지금 35%」처럼 한 줄로 합치는 것 검토.
- 「나누기」 카드 상단 「100% 다 나눴어요」와 「+55만 더 넣으면 50%」가 함께 보여 서로 반대처럼 읽힌다(비율은 다 나눴지만 항목이 덜 찼다는 뜻). 문구 다듬기.
- 연결 화면 「코드 붙여넣기」 대비 4.28.
- 바구니 편집 시트는 자동 검사에서 따로 잡히지 않아 눈으로만 봤다(다시 볼 것).

고친 것
- **어두운 모드 파란 큰 카드(흐름 · 나누기 실수령)가 밝은 하늘색이 돼 흰 글자 대비 2.45** → 카드 바탕을 `--hero-bg`(어두운 남색)로.
- **어두운 모드 매니저 「바로 맞추기」 빨간 버튼 흰 글자 대비 2.25** → 글자를 `--on-brand`로.
- 단위 필터 버튼 40 → 44px.
- 매니저 제안이 「-10.1%」처럼 소수로 나오던 것 → 정수 %로, 문장도 「○%를 줄이고, 나머지 ○%는 다른 바구니에서」.
