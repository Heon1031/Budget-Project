# 결정 기록

- [2026-11-03] 서버는 Cloudflare 하나(Workers + D1). GitHub는 코드 보관 · 자동 배포만. AWS · Vercel · 구글 Apps Script는 쓰지 않는다.
- [2026-11-03] 기록은 폰에서 AES-GCM으로 암호화해 보낸다(종단 간 암호화). 비밀번호를 잊으면 복구 불가 — 대신 엑셀 내보내기 제공.
- [2026-11-03] 두 폰 연결은 연결 코드(22자) + 비밀번호. 10번 틀리면 15분 잠금.
- [2026-11-03] 관리법은 통장 쪼개기. 약속 항목 = 통장. 공동 생활비만 기록하고, 각자 용돈은 묻지 않는다.
- [2026-11-03] 주택 상황: 전세 · 월세에서 1년 안 내 집 마련. 집 목돈은 원금 보장 상품에만.
- [2026-11-03] 규제 숫자는 추정 · 입력값으로 두고 출처 · 기준일을 `docs/housing.md`에 적는다.
- [2026-11-03] 주 색을 초록에서 푸른색(토스 느낌)으로 바꿈. 글꼴 Pretendard, 어두운 모드 지원.
- [2026-11-03] 금리는 한국은행 ECOS에서 매일 자동으로 받고, 대출 규제는 금융위원회 보도자료 소식만 알린다(숫자 반영은 사람이 확인 후).
- [2026-11-03] 자산 모아보기는 뱅크샐러드에 맡긴다. 이 앱 첫 화면은 「오늘 둘이 쓸 수 있는 돈」과 「내 집까지 남은 거리」.
- [2026-11-03] 앱의 자리를 「큰 흐름」으로 다시 정함: 고정지출(각자 · 공동) 목록 + 1년 모일 돈 + 이번 달 각자 마음 편히 쓸 돈 + 해볼까. 건별 지출 기록 · 약속 합의 · 월급날 체크 화면은 뺌(공동 생활비는 공동 고정지출 한 줄로).
- [2026-11-03] 자동으로 거래내역 읽기는 하지 않음 — 마이데이터 · 오픈뱅킹은 허가 사업자만 가능, 알림 읽기는 아이폰 불가 · 보안 원칙과 어긋남.
