# 설계 — 기능 · 화면 · 디자인 (2026-11-03 정함)

## 목표
「이거 사도 돼?」로 다투지 않게, **돈의 자리(통장)와 약속을 먼저 정하고 숫자가 답하게** 한다. 그리고 1년 안 내 집 마련까지 매달 얼마가 모자란지 보이게 한다.

## 관리법: 통장 쪼개기
월급이 들어오면 월급날 한 번에 각 통장으로 나눠 보낸다. 앱의 「이번 달 약속」 항목은 이 통장과 1:1로 맞춘다.

| 통장 | 약속 항목 | 규칙 |
|---|---|---|
| 월급 통장 | (들어오는 곳) | 월급날 바로 아래로 보낸다. 남겨 두지 않는다. |
| 고정 지출 통장 | 고정 지출 | 월세 · 대출 이자 · 공과금 · 통신 · 보험 자동이체 |
| 공동 생활비 통장(체크카드) | 공동 생활비 | 식비 · 장보기 · 문화 · 여행. 앱에 기록한다. |
| 각자 용돈 통장 | 용돈 | 묻지 않고 쓴다. 기록하지 않는다. |
| 비상금 통장 | 비상금 | 생활비 3~6개월치까지 채우고, 다 차면 집 목돈으로 돌린다. |
| 집 목돈 통장 | 집 목돈 | **1년 안에 쓸 돈이라 원금이 보장되는 곳**(예금 · 적금 · 파킹통장)에만 둔다. |
| 투자 통장 | 투자 | 5년 이상 안 쓸 돈만. 집 계약 전에는 비중을 줄인다. |

## 화면 구조 (아래 탭 4개)
1. **이번 달** — 위에서부터 남은 공동 생활비(큰 숫자) + 「이거 사도 돼?」 + 기록 목록 → 월급날 통장 나누기 체크 → 약속 요약 · 합의 → 엑셀 내보내기. 약속이 없으면 약속 정하기가 맨 위.
2. **집 마련** — 목표 집값 · 시기 → 필요한 현금 · 대출 가능액(추정) · 모자란 돈 · 매달 더 모을 돈, 일정 체크리스트(계약금 · 잔금 · 전세보증금 반환 · 전입)
3. **계획** — 연봉 · 실수령액 · 비율 계산(원래 화면)
4. **연결** — 두 폰 연결 · 동기화 상태

## 디자인 규칙
- 색: 초록(`--green` #185f54)이 주 색. 경고는 주황(#86501f/#f6ead9), 부족 · 위험은 붉은색(#994635/#f8e3de), 좋음은 연초록(#2f6a47/#e4f1e8).
- 숫자: 원 단위 쉼표, 큰 숫자는 Georgia 계열. 음수는 「○원 부족」처럼 말로 쓴다.
- 글자 12px 이상(보조 11px까지), 입력 칸 16px(아이폰 확대 방지), 누르는 곳 44px 이상.
- 카드 하나에 주 버튼(초록 꽉 찬 버튼) 하나. 나머지는 테두리 버튼.
- 추정 숫자에는 「추정」 표시와 기준일을 붙인다.
